# Além da Fronteira

Um platformer curto sobre atravessar a fronteira entre dois mundos.

## Controles

- Setas: mover
- Z: pular e confirmar

## Objetivo

Atravesse a fase, reúna os fragmentos e alcance o portal para abrir a fronteira.

## Arte

Os recortes em `art/` vêm do pacote Brackeys Platformer Assets, distribuído sob CC0. Fontes e créditos completos estão em `art/CREDITS.txt`.
